# Expense Tracker

A simple and responsive **Expense Tracker** built using HTML, CSS, and JavaScript. It allows users to manage income and expenses while keeping track of their current balance.

## Features

* Add income and expenses
* View total balance, income, and expenses
* Delete transactions
* Transactions are stored using **Local Storage**
* Currency formatting using JavaScript `Intl.NumberFormat`
* Responsive and clean interface

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Local Storage
